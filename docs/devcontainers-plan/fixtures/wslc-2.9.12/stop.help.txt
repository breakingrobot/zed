Arrête les conteneurs.

Utilisation : wslc stop [options] <container-id>...

Alias :
  wslc container stop, wslc stop

Arguments :
  container-id  ID de conteneur

Options :
  -s  --signal   Signal à envoyer (par défaut : STOPSIGNAL configuré du conteneur, ou SIGTERM si aucun n’est configuré)
  -t  --time     Secondes à attendre avant de tuer le conteneur (par défaut : délai d’expiration d’arrêt configuré du conteneur)
  -?  --help     Affiche l’aide sur la commande sélectionnée

Options globales :
      --session  Spécifiez la session à utiliser
